## Abstract

Vision-Language-Action (VLA) models pretrained on RGB video have demonstrated impressive transfer to downstream robotic manipulation tasks. However, a fundamental question remains underexplored: how can depth information be effectively incorporated into VLA models? Unlike RGB images, where high-level semantic features are often crucial, depth images primarily provide dense geometric information that is directly useful for action prediction rather than semantic understanding. Furthermore, it remains unclear whether knowledge learned from depth information in human demonstration data can be effectively transferred to robot manipulation tasks without relying on high-level semantic abstraction. Motivated by these unanswered questions, we present a systematic empirical study showing that spatial understanding emerges from high-level semantic abstractions within large language models (LLMs), rather than from the latent action labels used in LAPA. Based on this insight, we propose a lightweight depth-augmented extension of LAPA that introduces an additional depth feature encoder conditioned on frozen RGB latent action features. The depth encoder is trained on synthetic depth images generated by Depth Anything V2 from the Something-Something V2 dataset with no robotics-specific supervision. Despite this domain gap, combining depth encoder features with LAPA backbone features achieves $R^2 = 0.625$ for translation magnitude prediction, and D-LAPA improves over the LAPA baseline on both CALVIN long-horizon tasks (+0.18 avg. chain completion) and LIBERO-LONG (+6.4% success rate). We further show that removing depth inputs eliminates the performance gain, confirming that dense geometric information but not the pretraining priors alone drives the improvement.

**Keywords:** Robot Learning, Depth Perception, Latent Action Representations

## 1 Introduction

Vision-Language-Action (VLA) models pretrained on large video datasets have demonstrated impressive transfer to downstream robotic manipulation tasks. Methods like LAPA [1], Moto [2], and villa-X [3] train discrete latent action tokenizers on consecutive RGB frame pairs, distilling visual change into compact tokens that serve as a pretraining signal before fine-tuning on labeled demonstrations. Broader families of latent action methods, including VPT [4], LAPO [5], Genie [6], UniVLA [7], and IGOR [8], share the same core assumption: that inter-frame visual change can be compressed into reusable action tokens. Despite their empirical success, two fundamental questions remain underexplored: how can depth information be effectively incorporated into VLA models, and where does spatial understanding actually come from in these systems?

**Depth is geometrically distinct from RGB.** Unlike RGB images, where high-level semantic features drive action prediction, depth images provide dense geometric information that directly encodes metric displacement without requiring semantic abstraction. Recovering movement magnitude from RGB alone is inherently ambiguous — the same pixel displacement can correspond to vastly different physical displacements depending on scene depth and camera calibration. Yet it remains unclear whether knowledge learned from depth information in human demonstration data can transfer to robot manipulation without high-level semantic abstraction.

**Spatial understanding lives in the LLM, not the action labels.** A Ridge-probing study on 138,090 held-out LIBERO frame pairs reframes the design question. The latent action labels $a$ are weak predictors of end-effector translation magnitude. The strong predictor is the LLM's own 4096-dim internal feature ($R^2 = 0.619$), and concatenating our depth encoder feature on top reaches the empirical ceiling ($R^2 = 0.625$). Spatial understanding is an emergent property of the large-scale semantic backbone, not of the action-label channel — a conclusion compatible with concurrent diagnostic work on latent action models [9, 10], which shows the action-label channel primarily encodes controllable visual change.

**Depth encoder trained on human video transfers to robot tasks.** Based on this insight, we propose D-LAPA, a lightweight depth-augmented extension of LAPA that introduces a depth feature encoder conditioned on frozen RGB latent action features from the LAPA backbone. Crucially, the depth encoder is trained exclusively on synthetic depth images generated by Depth Anything V2 [11] from the Something-Something V2 (SSv2) dataset [12]. Despite this domain gap, the resulting depth features significantly improve performance on long-horizon language-conditioned robot manipulation tasks in the CALVIN benchmark [13].

**Our key contributions are:**

- We observed that post-VQ RGB latent tokens retain limited information about translation magnitude ($R^2 = 0.049$). The VQ bottleneck is the primary cause of this information collapse, reducing the predictive power from the pre-VQ MLP representation ($R^2 = 0.56$). This suggests that models trained with latent actions may suffer from insufficient spatial understanding.
- We propose that spatial understanding capabilities emerge in a depth image encoder pretrained on latent action extraction from non-robot synthetic depth images.
- We further demonstrate that this learned knowledge transfers effectively to robotic tasks without any additional fine-tuning on robot-related data.

## 2 Related Work

### 2.1 Latent Action Pretraining

LAPA [1] learns a VQ-VAE-style tokenizer on consecutive RGB frame pairs and uses the resulting latent tokens as a pretraining signal for VLA models via a C-ViViT encoder [14]. Moto [2] follows a similar VQ-based paradigm, pre-training a GPT model on latent motion token sequences. villa-X [3] improves codebook utilization and VLA integration. Continuous alternatives, CoMo [15] and CLAM [16], preserve motion fidelity without discrete bottlenecks, while FAST [17] proposes DCT-based action tokenization. CLAP [18] uses contrastive alignment of human-video latents with robot proprioception to reduce visual entanglement. To improve physical grounding, UniVLA [7] derives task-centric latent actions in the DINO feature space, IGOR [8] uses image-goal representations as atomic control units, and LatBot [19] disentangles latent actions into motion and scene components. Related methods VPT [4], LAPO [5], and Genie [6] extract latent representations from video without action labels. GR00T [20] uses latent actions to decouple high- and low-frequency control in generalist humanoid systems. The LARY benchmark [21] evaluates latent action representations across semantic and low-level control tasks, finding that general visual foundation models consistently outperform embodiment-specific latent action models — a finding consistent with our observation that spatial understanding originates in the LLM's own representations rather than in the action labels. Concurrent diagnostic work [9, 10, 22] shows that RGB latent actions primarily encode controllable visual change while conflating distractors with task-relevant motion; our study complements this by identifying that the LLM's internal features, not the action labels, are the true carriers of geometric information, and by showing that depth-derived features trained purely on human video can fill this gap.

### 2.2 Depth in Robot Learning

Depth sensing has a long history in robot manipulation through point clouds [23, 24] and RGBD encoders [25]. Depth Helps [26] injects RGBD supervision into pretrained RGB policies via a Depth-Aware Codebook, providing the closest architectural precedent to our approach. QDepth-VLA [27] uses VQ-quantized depth tokens as auxiliary supervision, combining depth grounding with discrete tokenization. Spatial Forcing [28] aligns VLA visual embeddings with frozen 3D-foundation-model features without requiring a depth sensor at test time. PointVLA [29] and Any3D-VLA [30] inject 3D point-cloud representations into pretrained VLAs, with Any3D-VLA finding that depth representation rather than mere depth presence drives improvement — directly supporting our thesis. DreamVLA [31] predicts future depth maps as world knowledge for action planning. UniLACT [32] learns a shared RGB-depth embedding via inverse and forward dynamics; MVP-LAM [33] addresses viewpoint dependence via cross-viewpoint reconstruction. Our work differs from all of the above in two critical ways: (1) we trace the geometric information specifically to the LLM's internal semantic representations rather than to the action supervision labels, (2) we use depth image as a direct input of the system rather than only use it in the training phase, and (3) we demonstrate that a depth encoder trained entirely on human video (SSv2) transfers to robot manipulation without any robot-domain fine-tuning.

## 3 Feature Analysis

### 3.1 Setup

We probe the geometric content of five Stage-2.5 depth-encoder variants (Models 1–5) on LIBERO-10 [34] together with two reference families: (i) the four LAQ supervision targets used in Stage-1 (pre-/post-VQ LAPA LAQ; pre-/post-VQ SSv2 depth tokeniser), and (ii) the finetuned-LAPA RGB feature — LAPA-7B with its latent-action pretraining objective continued on the LIBERO trajectory distribution.

**Protocol.** We use 138,090 consecutive frame pairs from LIBERO-10, split 80/20 by `video_id` (seed 42, $n_\text{train}=111{,}284$, $n_\text{test}=26{,}806$); probes are similar to those used in recent latent-action diagnostics [9, 10]. The probe target is normalised per-step end-effector translation magnitude $|\Delta t|$. We fit a Ridge regression with closed-form GCV over $\alpha \in \{10^{-5}, \ldots, 10^{5}\}$ and a two-hidden-layer MLP. Features are z-score standardised on the training split only and we report test-set $R^2$ and Spearman $\rho$. Each Stage-2.5 model is additionally probed at eight SSv2 checkpoints (0–65k steps).

**Finding A: The spatial concept does not lay in the labels.** The latent labels created from the LAQ in Stage 1 show low correlation with the movement magnitude while the features from finetuned LAPA show a high $R^2$ value.

**Finding B: Depth information injection improves the correlation.** The $R^2$ value from a combination of features from finetuned LAPA and the depth encoder Model 4 is higher than the others. While the model with no depth image input (Model 3 and Model 5) present no improvement.

**Limitations.** The probe target is a single scalar ($|\Delta t|$) on one robot benchmark (LIBERO-10). Held-out videos share task structure with the training split, so probe $R^2$ is an in-distribution decodability measure and is not by itself a predictor of policy success; we report downstream policy results in Section 4. The finetuned-LAPA reference is itself trained on LIBERO trajectories, so the ceiling it sets is in-distribution by construction.

## 4 Depth-Augmented via Latent Action Pretraining

### 4.1 Design Principles

Given the diagnostic findings, we add depth with three constraints: (1) reuse existing LAPA checkpoints without re-pretraining, (2) keep the depth component computationally lightweight, and (3) isolate the depth contribution cleanly for ablation.

> **Figure 2:** Depth representation learning pipeline. Stage 1 pretrains a depth teacher from paired depth frames and provides ground-truth `z_depth_feature` after being frozen. Stage 2.5 trains a lightweight depth encoder to predict this feature from the current depth image and frozen LAPA RGB feature using an MSE plus cosine loss.

### 4.2 Our Designed Stage 2.5 Model Variants

Our main contribution in this work is the design and comparison of a family of lightweight Stage 2.5 modules for injecting depth information into LAPA. Figure 2 illustrates the main feature-distillation pipeline used by Model 4, while Table 2 summarizes all Stage 2.5 variants considered in our ablation study. Rather than modifying the original LAPA backbone, we keep the RGB-language model frozen and train a lightweight depth module that produces a depth-aware representation for downstream action prediction. This design allows us to reuse existing LAPA checkpoints, avoid expensive re-pretraining, and isolate the effect of depth through controlled ablations.

The Stage 2.5 module is trained using supervision from a separately trained Stage 1 depth tokenizer. Given a pair of depth frames, the Stage 1 tokenizer produces discrete depth latent indices $z^\text{depth-idx}_t$ and a continuous depth teacher feature $z^\text{depth-feat}_t$. We use these two supervision signals to construct two families of Stage 2.5 objectives. The first family, Models 1–3, learns a depth representation indirectly by predicting discrete depth indices. The second family, Models 4–5, directly distills the continuous depth teacher feature. The details about the different models are presented in Appendix B.

**Table 2:** Summary of our designed Stage 2.5 variants. Models 1–3 learn depth representations indirectly through depth-token classification, while Models 4–5 directly distill continuous depth features from the Stage 1 depth teacher.

| Variant | Input | Downstream output | Supervision / loss |
|---|---|---|---|
| Model 1 | $D_t + z^\text{rgb-idx}_t$ | hidden $h^D_t$ | $z^\text{depth-idx}_t$ / CE |
| Model 2 | $D_t + z^\text{rgb-feat}_t$ | hidden $h^D_t$ | $z^\text{depth-idx}_t$ / CE |
| Model 3 | $z^\text{rgb-feat}_t$ | hidden $h^D_t$ | $z^\text{depth-idx}_t$ / CE |
| Model 4 | $D_t + z^\text{rgb-feat}_t$ | predicted $\hat{z}^D_t$ | $z^\text{depth-feat}_t$ / MSE + cosine |
| Model 5 | $z^\text{rgb-feat}_t$ | predicted $\hat{z}^D_t$ | $z^\text{depth-feat}_t$ / MSE + cosine |

These five variants provide controlled comparisons. Model 1 versus Model 2 measures the effect of discrete versus continuous RGB conditioning. Model 2 versus Model 3 measures the added value of the explicit depth image under depth-token classification. Model 4 versus Model 5 measures the added value of the explicit depth image under continuous feature distillation. Finally, Models 1–3 versus Models 4–5 compare indirect depth-token supervision against direct depth-feature distillation.

### 4.3 Training Details

**Stage 1: depth tokenizer pretraining.** We train the Stage 1 depth tokenizer on a subset of 30k action videos from Something-Something V2 [12]. For each video, we use aligned depth-frame pairs $(D_t, D_{t+\Delta})$ as input to the depth tokenizer. The tokenizer maps each depth-frame pair to four discrete depth latent indices using a codebook of size $K = 8$. We train the tokenizer for 25k optimization steps. After training, the Stage 1 tokenizer is frozen and used offline on the same 30k-video subset to generate supervision for Stage 2.5, including the discrete depth indices $z^\text{depth-idx}_t \in \{1, \ldots, K\}^4$ and the continuous depth teacher feature $z^\text{depth-feat}_t \in \mathbb{R}^{1024}$.

**Stage 2.5: conditioned depth representation learning.** We train all Stage 2.5 variants on the same 30k-video subset used for Stage 1. The inputs are constructed from aligned RGB frames, estimated depth maps, and frozen LAPA RGB representations. The frozen LAPA model is run offline to extract both discrete RGB latent indices $z^\text{rgb-idx}_t$ and continuous RGB features $z^\text{rgb-feat}_t \in \mathbb{R}^{4096}$.

Models 1–3 are trained as depth-token classification models: each predicts four depth-token logits and is optimized with cross-entropy against $z^\text{depth-idx}_t$. Models 4–5 are trained as feature-distillation models: each predicts a 1024-dimensional depth feature and is optimized using mean-squared error plus cosine-distance loss against $z^\text{depth-feat}_t$, with $\lambda_\text{cos} = 0.1$. All Stage 2.5 variants are trained with AdamW, a learning rate of $10^{-4}$, batch size 128, and 65k optimization steps. During training, both the original LAPA backbone and the Stage 1 depth teacher are frozen; only the lightweight Stage 2.5 module is updated.

Our evaluation is designed to answer three core questions: (1) Does the performance gain of our model stem from the depth image itself, or merely from the added parameters in the Stage 2.5 architecture? (2) What is the optimal conditioning strategy for the depth encoder? (3) Do these enriched latent representations translate to superior long-horizon manipulation capabilities on physical tasks?

We evaluate the downstream manipulation capabilities of our models to test their ability to handle extended sequential tasks and generalize across complex spatial configurations, which heavily rely on precise geometric grounding.

### 5.3 Architectural Ablations and Analysis

The design of our Stage 2.5 variants allows us to systematically isolate the causal source of our performance gains and determine the optimal conditioning strategy.

**Isolating the Depth Contribution:** The most critical comparison lies between Model 4 and the capacity control (Model 5). Both utilize the identical feature-distillation architecture, but Model 5 operates without the explicit depth image input. While Model 4 improves upon the baseline by 6.4% on LIBERO-LONG, Model 5's performance regresses to 77.4% — slightly below the baseline. This capacity-controlled ablation demonstrates that the added parameters alone cannot hallucinate the missing geometric information from RGB features. The substantial performance gap explicitly confirms that the raw depth image is the operative source of the performance gain. A similar, though less severe, drop is observed between the discrete-supervision variants, where removing depth drops performance from 83.2% (Model 2) down to 80.2% (Model 3).

**Continuous vs. Discrete Conditioning:** Our results also validate our architectural choices for the Stage 2.5 conditioning. Models conditioned on continuous RGB features (Model 2 and Model 4) consistently outperform Model 1, which relies on discrete RGB indices (83.2% and 84.2% vs. 79.8%). This suggests that the continuous RGB feature space provides a richer semantic context, better steering the depth encoder to focus on residual geometric and contact information rather than redundantly encoding visual semantics.

## 6 Conclusion

We have presented a systematic investigation of how geometric information flows through latent action pretraining pipelines, and a lightweight architectural extension that addresses the identified gap. Our probing study establishes that post-VQ RGB latent tokens are poor carriers of translation magnitude ($R^2 = 0.006$), and that this poverty is caused by the VQ bottleneck collapsing the pre-VQ geometric structure ($R^2 = 0.454$ for an MLP on continuous encoder outputs) into appearance-based clusters. Crucially, we show that spatial understanding in LAPA originates in the LLM's own internal representations ($R^2 = 0.619$), not in the action supervision signal — a result that reframes how we should think about the geometric competence of VLA models.

Building on this insight, we propose a framework which augments LAPA with a lightweight depth encoder trained via feature distillation on synthetic depth images from Something-Something V2. Despite being trained entirely on human video with no robot-domain supervision, it achieves $R^2 = 0.626$ for translation magnitude prediction and improves over the LAPA baseline by +6.4% on LIBERO-LONG and +0.18 average chain completion on CALVIN. A capacity-controlled ablation (Model 5) demonstrates conclusively that these gains arise from the depth signal itself, not from added model capacity.

Taken together, our findings make a strong case for incorporating geometric modalities at the pretraining stage of VLA pipelines, and demonstrate that depth knowledge learned from large-scale human video is directly reusable for robot control. We hope this work motivates further investigation into metric-preserving quantization schemes, richer probing methodologies for physical grounding, and scalable approaches to cross-embodiment geometric transfer.

## Appendix A: Dataset

We use different datasets for representation pretraining, diagnostic probing, and downstream policy evaluation. Table 5 and Table 6 summarize how each dataset is used in our pipeline.

### A.1 Source Datasets

We use the first 30k videos from the Something-Something V2 (SSv2) training set as the main pretraining dataset for Stage-1 and Stage-2.5 representation learning. For the stronger depth teacher and its corresponding Stage-2.5 variants, we additionally use LIBERO-90, forming a mixed pretraining corpus of first-30k-SSv2 + LIBERO-90. LIBERO-LONG is used for downstream long-horizon manipulation evaluation.

### A.2 Frame-Pair Construction

Each pretraining sample is a temporal transition. For RGB frames, we denote a pair as $(I_t, I_{t+\Delta})$; for depth frames, we denote the aligned pair as $(D_t, D_{t+\Delta})$. Stage-1 teachers are trained from paired RGB or depth frames. Stage-2.5 models observe $D_t$, frozen LAPA RGB features $z^\text{rgb-feat}_t$, frozen LAPA RGB indices $z^\text{rgb-idx}_t$, or their combination, and predict pseudo-labels generated by frozen Stage-1 teachers.

### A.5 LIBERO-LONG Probe and Downstream Evaluation

For diagnostic probing, we use LIBERO-LONG and compute the end-effector translation magnitude for each frame pair:

$$|\Delta t| = \|p_{t+\Delta} - p_t\|_2$$

The probing split is performed by video or trajectory id to avoid leakage between train and test pairs. For downstream evaluation, we also use LIBERO-LONG and keep the same training and evaluation protocol across all model variants.

## Appendix B: Model Design

**Model 1: depth image with RGB-index conditioning.** Model 1 takes the current depth image $D_t$ and the frozen LAPA RGB latent indices $z^\text{rgb-idx}_t$ as input. The depth module produces an intermediate depth feature $h^D_t$, which is then passed to a linear classification head to predict logits over the depth codebook:

$$h^D_t = f^{(1)}_\phi\!\left(D_t,\, z^\text{rgb-idx}_t\right), \quad \hat{\ell}^D_t = g^{(1)}_\phi(h^D_t)$$

where $\hat{\ell}^D_t \in \mathbb{R}^{4 \times K}$ and $K = 8$. Model 1 is trained only with cross-entropy supervision against the Stage 1 depth indices:

$$\mathcal{L}_{M1} = \text{CE}\!\left(\hat{\ell}^D_t,\, z^\text{depth-idx}_t\right)$$

The intermediate feature $h^D_t$ is used as the depth representation in later fusion, but it is not directly supervised by a feature regression loss.

**Model 2: depth image with RGB-feature conditioning.** Model 2 replaces the discrete RGB-index conditioning in Model 1 with a continuous RGB feature $z^\text{rgb-feat}_t$ extracted from frozen LAPA. It uses the same depth encoder and classification head structure:

$$h^D_t = f^{(2)}_\phi\!\left(D_t,\, z^\text{rgb-feat}_t\right), \quad \hat{\ell}^D_t = g^{(2)}_\phi(h^D_t)$$

$$\mathcal{L}_{M2} = \text{CE}\!\left(\hat{\ell}^D_t,\, z^\text{depth-idx}_t\right)$$

This variant tests whether continuous RGB features provide more useful conditioning than discrete RGB latent indices for predicting depth tokens.

**Model 3: RGB-feature-only depth-token prediction.** Model 3 removes the explicit depth image and predicts depth indices using only the frozen LAPA RGB feature:

$$h^D_t = f^{(3)}_\phi\!\left(z^\text{rgb-feat}_t\right), \quad \hat{\ell}^D_t = g^{(3)}_\phi(h^D_t)$$

$$\mathcal{L}_{M3} = \text{CE}\!\left(\hat{\ell}^D_t,\, z^\text{depth-idx}_t\right)$$

Model 3 serves as an ablation for testing whether the frozen RGB feature alone already contains enough information to infer the discrete depth transition tokens.

**Model 4: depth image and RGB-feature conditioned feature distillation.** Model 4 is our default Stage 2.5 design. It takes both the current depth image $D_t$ and the frozen LAPA RGB feature $z^\text{rgb-feat}_t$ as input, and directly predicts the continuous Stage 1 depth teacher feature:

$$\hat{z}^D_t = f^{(4)}_\phi\!\left(D_t,\, z^\text{rgb-feat}_t\right)$$

Unlike Models 1–3, Model 4 does not use a depth-token classification loss. Instead, it is trained with feature distillation:

$$\mathcal{L}_{M4} = \left\|\hat{z}^D_t - z^\text{depth-feat}_t\right\|^2_2 + \lambda_\text{cos}\!\left(1 - \cos\!\left(\hat{z}^D_t,\, z^\text{depth-feat}_t\right)\right)$$

where $\lambda_\text{cos} = 0.1$. The MSE term preserves the absolute feature values, while the cosine term encourages the predicted feature to align with the teacher representation direction.

**Model 5: RGB-feature-only feature distillation.** Model 5 removes the explicit depth image from Model 4 and predicts the continuous depth teacher feature using only the frozen RGB feature:

$$\hat{z}^D_t = f^{(5)}_\phi\!\left(z^\text{rgb-feat}_t\right)$$

$$\mathcal{L}_{M5} = \left\|\hat{z}^D_t - z^\text{depth-feat}_t\right\|^2_2 + \lambda_\text{cos}\!\left(1 - \cos\!\left(\hat{z}^D_t,\, z^\text{depth-feat}_t\right)\right)$$

Model 5 tests whether the frozen RGB feature can hallucinate the continuous depth representation without observing the depth image.

## Appendix C: Model Architecture Details

This section provides additional architectural details for the Stage-1 teacher models and the Stage-2.5 depth representation models used in our experiments. Our pipeline consists of three stages. Stage 1 trains teacher models that extract depth or RGB transition representations from paired frames. Stage 2.5 trains a lightweight depth-aware encoder using pseudo-labels generated by a frozen Stage-1 teacher. Stage 3 freezes the vision-side representation encoders and fine-tunes the language model and action head for downstream robot action prediction.

### C.1 Overall Pipeline

Given a temporal transition $(I_t, I_{t+\Delta}, D_t, D_{t+\Delta})$, the original LAPA model extracts RGB latent representations from RGB frame pairs. Our goal is to add a lightweight depth pathway that provides complementary geometric information. We keep the LAPA visual components frozen and train a small Stage-2.5 module for depth-aware representation learning. Depending on the model variant, the Stage-2.5 module receives the current depth map $D_t$, the frozen LAPA RGB feature $z^\text{rgb-feat}_t$, the frozen LAPA RGB indices $z^\text{rgb-idx}_t$, or their combination.

The Stage-2.5 module outputs a 1024-dimensional depth-aware representation. For downstream policy learning, this representation is concatenated with the LAPA RGB feature and used by the action prediction module.

### C.2 Stage-1 Teacher Models

The Stage-1 models are trained first and then frozen. Their role is to generate pseudo-labels for Stage-2.5 training.

**Model 1.1-depth.** Model 1.1-depth is a depth-only teacher trained from paired depth frames $(D_t, D_{t+\Delta})$. The encoder maps the depth transition into a continuous depth feature $z^\text{depth-feat}_t$, which is then quantized into discrete depth indices $z^\text{depth-idx}_t$. The decoder reconstructs the future depth frame $D_{t+\Delta}$ from the latent depth feature and the current depth frame $D_t$. This model provides pseudo-labels for Stage-2.5 Models 1–5.

### C.3 Stage-2.5 Models

All Stage-2.5 models are lightweight encoders trained with frozen LAPA features and frozen Stage-1 pseudo-labels. They differ in input modality, pseudo-label source, and supervision type.

**Models 1–3: depth-index prediction.** Models 1–3 are trained to predict discrete depth indices generated by the Stage-1 depth teacher. Model 1 uses the current depth map and frozen RGB latent indices. Model 2 replaces RGB indices with the continuous frozen LAPA RGB feature. Model 3 removes the explicit depth input and predicts depth indices using only the RGB feature. Thus, Model 3 serves as a no-depth control for the index-prediction setting.

**Table 7:** Stage-2.5 architecture variants. CE denotes cross-entropy loss for depth-index prediction, while MSE+cos denotes continuous feature distillation.

| Model | Input | Prediction target | Loss |
|---|---|---|---|
| Model 1 | $D_t + z^\text{rgb-idx}_t$ | $z^\text{depth-idx}_t$ | CE |
| Model 2 | $D_t + z^\text{rgb-feat}_t$ | $z^\text{depth-idx}_t$ | CE |
| Model 3 | $z^\text{rgb-feat}_t$ | $z^\text{depth-idx}_t$ | CE |
| Model 4 | $D_t + z^\text{rgb-feat}_t$ | $z^\text{depth-feat}_t$ | MSE+cos |
| Model 5 | $z^\text{rgb-feat}_t$ | $z^\text{depth-feat}_t$ | MSE+cos |

**Models 4–5: depth-feature distillation.** Models 4–5 are trained to predict the continuous depth feature generated by the Stage-1 depth teacher. Model 4 uses both the current depth map and the frozen LAPA RGB feature. Model 5 removes the depth input and uses only the RGB feature. Therefore, Model 5 is a capacity-matched no-depth control for Model 4.

### C.4 Loss Functions

For index-prediction models, the Stage-2.5 encoder predicts four depth-token logits and is optimized with cross-entropy:

$$\mathcal{L}_\text{idx} = \text{CE}\!\left(\hat{z}^\text{depth-idx}_t,\, z^\text{depth-idx}_t\right)$$

For feature-distillation models, the Stage-2.5 encoder predicts a 1024-dimensional continuous depth feature and is optimized with an MSE loss plus a cosine-distance loss:

$$\mathcal{L}_\text{feat} = \left\|\hat{z}^D - z^\text{depth-feat}\right\|^2_2 + \lambda_\text{cos}\!\left(1 - \cos\!\left(\hat{z}^D,\, z^\text{depth-feat}\right)\right)$$

We set $\lambda_\text{cos} = 0.1$ in all feature-distillation experiments.

### C.5 Downstream Policy Input

For downstream policy learning, the selected Stage-2.5 encoder is frozen. The policy receives the LAPA RGB feature together with the learned depth-aware feature:

$$z^\text{policy}_t = \left[z^\text{rgb-feat}_t;\; z^\text{depth-feat}_t\right]$$

Following the LAPA action fine-tuning protocol, the LAPA vision encoder is frozen while the LAPA language model and action head are fine-tuned. In our setting, the Stage-2.5 depth encoder is additionally frozen so that differences across variants reflect the quality of the learned depth representation.

## Appendix D: Hyperparameters and Training Details

This section summarizes the training details for the three stages of our pipeline: Stage 1 teacher training, Stage 2.5 depth representation learning, and Stage 3 downstream action fine-tuning.

### D.1 Stage 1: Teacher Training

Stage 1 trains latent action quantization (LAQ) teacher models from paired frames. For the depth-only teacher, the model takes a pair of depth frames $(D_t, D_{t+\Delta})$ as input. The encoder produces a continuous latent feature $z^\text{depth-feat}$, which is quantized into four discrete latent codes $z^\text{depth-idx}$. The decoder reconstructs the future depth frame $D_{t+\Delta}$ from the latent representation and the current depth frame $D_t$.

The main Stage-1 depth teacher, Model 1.1-depth, is trained on the first 30k videos from SSv2.

**Table 8:** Stage-1 training hyperparameters.

| Hyperparameter | Value |
|---|---|
| Input resolution | 256 × 256 |
| Temporal offset | 30 |
| Latent dimension | 1024 |
| Quantization dimension | 32 |
| Codebook size | 8 |
| Code sequence length | 4 |
| Patch size | 32 |
| Spatial depth | 8 |
| Temporal depth | 8 |
| Attention heads | 16 |
| Head dimension | 64 |
| Batch size | 64 |
| Learning rate | $1 \times 10^{-4}$ |
| Training steps | 25k |

After training, the Stage-1 teacher is frozen and used to extract pseudo-labels for Stage 2.5, including both discrete depth indices $z^\text{depth-idx}$ and continuous depth features $z^\text{depth-feat}$.

### D.2 Stage 2.5: Depth Representation Learning

Stage 2.5 trains a lightweight depth-aware encoder using frozen LAPA RGB representations and pseudo-labels generated by the frozen Stage-1 teacher. Depending on the model variant, the input is $D_t$, $z^\text{rgb-feat}_t$, $z^\text{rgb-idx}_t$, or their combination. The model outputs a 1024-dimensional depth-aware feature. For index-prediction variants, the output is passed to a classification head to predict $z^\text{depth-idx}$. For feature-distillation variants, the output is directly trained to match $z^\text{depth-feat}$.

The Stage-2.5 dataset loads pre-extracted LAPA RGB features from a feature manifest and depth pseudo-labels. Depth images are resized to 256 × 256, repeated to three channels when needed, and normalized by their storage range. When depth maps are stored as 16-bit images, we divide pixel values by 65535.0.

**Table 9:** Stage-2.5 training hyperparameters.

| Hyperparameter | Value |
|---|---|
| Input resolution | 256 × 256 |
| Latent dimension | 1024 |
| Codebook size | 8 |
| Code sequence length | 4 |
| Patch size | 32 |
| Spatial depth | 8 |
| Attention heads | 16 |
| Head dimension | 64 |
| Batch size | 128 |
| Gradient accumulation | 1 |
| Learning rate | $1 \times 10^{-4}$ |
| Training steps | 65k |

For depth-index prediction models, we use cross-entropy loss. For feature-distillation models, we use MSE plus cosine-distance loss with $\lambda_\text{cos} = 0.1$.

### D.3 Stage 3: Downstream Action Fine-Tuning

In Stage 3, we follow the action fine-tuning protocol of LAPA. The latent action head is replaced with a newly initialized robot action head. The LAPA vision encoder and VQGAN are frozen, while the LAPA language model and the action head are fine-tuned on downstream robot demonstrations. In our setting, we additionally freeze the Stage-2.5 depth encoder, which provides a fixed depth-aware representation for downstream action prediction.

**Table 10:** Stage-3 downstream fine-tuning hyperparameters.

| Hyperparameter | Value |
|---|---|
| Trainable modules | LAPA language model, action head |
| Frozen modules | LAPA vision encoder, VQGAN, Stage-2.5 encoder |
| Batch size | 16 |
| Training steps | 20k |
| Learning rate | $2 \times 10^{-5}$ |

This three-stage setup isolates the effect of depth representation learning. Stage 1 learns depth transition pseudo-labels, Stage 2.5 learns a compact depth-aware feature from frozen RGB representations and depth input, and Stage 3 evaluates whether this frozen depth-aware representation improves downstream action prediction under the LAPA action fine-tuning protocol.
